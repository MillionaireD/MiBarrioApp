# 🏘️ MiBarrioApp

MiBarrioApp es una aplicación web comunitaria que permite a los residentes de un barrio mantenerse informados sobre eventos, noticias, reportes vecinales, mapas y contacto directo con la administración. Diseñada para fortalecer la comunicación local, promover la participación ciudadana y facilitar la gestión de mejoras comunitarias.

---

## 📌 Características

- 📰 **Noticias del barrio**: Visualización de noticias con imágenes y modales informativos.
- 📣 **Reportar incidentes**: Sección para que los vecinos informen problemas o sugerencias.
- 🗺️ **Mapa comunitario**: (En desarrollo) permitirá ver ubicaciones de interés o incidentes reportados.
- 📬 **Formulario de contacto**: Para enviar sugerencias, preguntas o comentarios.
- 📱 **Diseño responsive**: Adaptado para móviles y pantallas de escritorio.
- ☁️ **Despliegue en GitHub Pages** (opcional): Puede ser consultado directamente desde navegador.

---

## 🛠️ Tecnologías utilizadas

- HTML5, CSS3 y JavaScript (Vanilla), JQuery
- Diseño responsivo (media queries)
- Bootstrap (ligero para modales, si lo estás usando)
- [Laragon](https://laragon.org/) o servidor local (opcional)
- Git + GitHub para control de versiones

## 🚀 ¿Cómo correr el proyecto?

Puedes correrlo directamente desde tu navegador abriendo `index.html`.

### O con un servidor local (recomendado):

1. Instala una herramienta como [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) en VS Code.
2. Haz clic derecho sobre `index.html` > **"Open with Live Server"**.

## 🧪 Funcionalidades destacadas

| Función               | Descripción                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| Noticias con modales  | Al hacer clic en una noticia, se abre un modal con más información.         |
| Botón "Volver arriba" | Botón flotante para regresar al inicio de la página.                        |
